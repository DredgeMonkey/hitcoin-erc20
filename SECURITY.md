# Security & Disclosure

This repository is a **historical educational/public evidence release**, not a production-ready or audited financial application. Please do not deploy or integrate the contract in a live financial system without independent review, appropriate testing, and a clearly understood threat model.

No personal wallet addresses, transaction hashes, seed phrases, private keys, wallet backups, access tokens, or identity-linked account metadata are intentionally included. For operational security, do not post any such values in issues, pull requests, discussions, screenshots, or forks.

If you believe you have found a security issue in the Solidity implementation, do not assume public disclosure of an exploit is necessary; use GitHub's private vulnerability reporting where enabled, or contact the repository maintainer privately.

A successful content scan is only a heuristic check; it does not prove that a publication is free of all potentially sensitive metadata. Human review remains required before publishing additional files.
